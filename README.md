# Marisa.QuickChat

Alife 4.x 桌宠插件。按全局快捷键（默认 `Alt+Q`）在鼠标位置呼出一个磨砂半透明悬浮窗，直接和已激活的桌宠说话 —— 不用切窗口、不用离开当前在干的事。

支持**私聊**和**群聊**，聊天记录会落盘，重启后还能往前翻。角色也可以自己调工具翻记录、发言、拉群。

> ⚠️ **安装时目录必须命名为 `Marisa.QuickChat`**
> 仓库名是 `Alife.QuickChat`，但代码里是按**插件目录名**定位自己的资源目录的（`Resources/QuickChat`）。
> 从 GitHub 下载的压缩包默认叫 `Alife.QuickChat-main`，直接丢进去会找不到资源、窗口起不来。**请先改名。**

## 功能

### 对话

- 全局快捷键呼出 / 隐藏，默认 `Alt+Q`
- 多个已激活桌宠之间切换；私聊支持多开（同一条线可以开好几条，各自独立记录）
- **流式输出**：模型边生成边显示，气泡实时增长、末尾带闪动光标。输出长时不用干等（可关闭）
- Markdown 基础渲染：标题、粗体、斜体、删除线、代码、列表、引用、表格、链接、分割线
- 自适应高度、最小化为输入条

### 群聊

- 左侧书签栏，含默认的「公共大厅」（当前所有已激活角色都在里面）和自建小群
- 群聊窗口自动加宽，聊得开
- 角色之间可以**互相接话**，但有闸门控制，不会没完没了刷屏：
  - 主人发言一定会投递给全部成员
  - 别的角色发言时，按「旁听概率」决定要不要叫醒你；被 @ 过之后的一段时间用更高的「活跃会话旁听概率」
  - 主人起的话头最多接 N 轮，到顶自动断路（主人随时可以重新起头）
- 角色**必须调 `QuickChatSend` 才算发言**，普通文字回复不会进群（这是刻意的：否则它在别处自言自语也会刷到群里）

### 聊天记录

- 私聊和群聊分别落盘，重启后仍可翻看
- 窗口向上滚动到顶部会自动加载更早的一页
- **角色自己也能翻**：调 `QuickChatRead` 可以读任意它参与的会话，用 `before` 游标一直往前翻到会话开头
- 清理按钮带二次确认，可选择是否连磁盘上的原始记录一起删

### 附件与截图

- 标题栏 `📷` 截全屏、`✂️` 截区域，截完直接发给当前会话
- `＋` 选择图片或文件；复制 / 粘贴的图片会自动存到插件目录下
- 拖动图片到消息区直接发送，拖到输入区加入等待区
- 等待区显示缩略图，点击可看原图
- 发给模型的是**本机路径**，由模型 / 其他插件按能力读取

### 外观

- 11 种配色预设（深空、墨黑、雾白、蓝色、青色、绿色、紫色、樱粉、暖橙、透明、自定义）
- 磨砂底色、消息区、气泡、输入框的底色与透明度都可单独调

## 安装

1. 把整个插件目录复制到 Alife 的插件目录下，**并确保目录名叫 `Marisa.QuickChat`**：

   ```text
   Alife/Storage/Plugins/Marisa.QuickChat
   ```

2. 重启 Alife（插件源码会在启动时自动编译）。
3. 在模块配置中启用「快聊」，并按需调整配置。
4. 按 `Alt+Q` 呼出窗口。

## 配置项

在 Alife 的模块配置里可以调整。下面按配置页的分组列出。

### 窗口与显示

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 全局快捷键 | `Alt+Q` | 至少保留一个；Electron Accelerator 格式 |
| 悬浮窗宽度 | `320` | 始终表示**聊天区**宽度（开群聊后左侧轨道会自动加上去） |
| 最大悬浮窗高度 | `460` | 自适应高度时也是展开历史后的上限 |
| 自适应高度 | 开 | 窗口高度随消息数量变化 |
| 最小悬浮窗高度 | `96` | 自适应模式下的下限 |
| 单次加载消息数 | `6` | 初次显示最近 N 条，滚到顶部再加载 N 条 |
| 显示所有消息 | 开 | 关闭「单次加载」限制，一次显示全部 |
| Esc 隐藏窗口 | 开 | |
| 标记消息来源 | 开 | 内部标记来源为 QuickChat，不显示在对话内容里 |
| 截图图片输入模式 | 多模态 | `临时分析` / `多模态` / `仅路径` |

### 外观

`基础配色`、`磨砂底色` + 透明度、`消息区` / `桌宠气泡` / `用户气泡` / `输入框` 的底色与透明度、`文字颜色`、`拖放图片模糊强度`。

底色支持 `#RRGGBB` 或基础色名（黑、白、灰、红、蓝、绿、黄、紫、粉、橙、青）。选非「自定义」的配色预设会覆盖下面的单项颜色。

### 消息显示

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 流式输出 | 开 | 关掉则等整轮生成结束再一次性出现，长输出会有明显等待感 |

### 群聊

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用群聊 | 开 | 关闭后只保留私聊 |
| 侧栏悬停展开 | 关 | 开启后鼠标扫过左侧轨道就自动弹开面板 |
| 公共大厅名称 | `萝卜开会` | 默认群聊的名字 |
| 群聊窗口宽度 / 高度 | `620` / `560` | 切到群聊时自动放大 |
| 群聊列表 | 空 | 自建小群：群名 + 成员（留空 = 当前所有已激活角色） |

### 记录与分页

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 保存私聊记录 | 开 | 关闭则关窗即丢 |
| 保存群聊记录 | 开 | 临时开会那种场合可以关掉 |
| 历史分页条数 | `20` | 每次从磁盘加载多少条 |
| 角色读取历史默认条数 | `30` | 角色调 `QuickChatRead` 不填条数时读多少条（上限 100） |
| 清理默认包含原始记录 | 开 | 清理弹窗里那个勾选框的默认状态 |

### 群聊投递门槛

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用自动投递 | 开 | 收到群聊消息时主动唤醒角色 |
| 单批最大消息数 | `16` | 一次合并投递最多带多少条 |
| 投递时附带上下文 | `0` | 投递时附带此前若干条消息，帮助进入语境 |
| 漏回复时自动提醒 | 开 | 角色回了却没发到群里时提醒它补上 |
| 群聊旁听概率 | `0.12` | 别的角色说话且没 @ 你时，仍投递给你的概率 |
| 活跃会话旁听概率 | `0.5` | 被 @ 之后的一段时间用这个概率 |
| 角色接话轮数上限 | `3` | 主人起头后角色之间最多互相接几轮 |
| 群聊静默时长 | `20` 分钟 | 超过该时长没有新 @ 就退回普通旁听概率 |
| 消息合并窗口 | `2.5` 秒 | 这段时间内的连续群消息合并成一次投递 |
| 每分钟最大投递轮次 | `12` | 超出后延迟投递，避免互相刷屏 |

## 角色能用的工具

插件的函数说明**不会**自动进系统提示词，而是由 `QuickChatAgentPrompt` 手写注入。角色可以做这些事：

| 工具 | 作用 |
| --- | --- |
| `QuickChatList` | 列出自己参与的全部会话（ID、标题、成员、未读数） |
| `QuickChatRead` | 读某个会话的记录，`before` 游标可一直往前翻 |
| `QuickChatSend` | 在**群聊**里发言（群聊必须用它才算发言） |
| `QuickChatDirect` | 主动找另一个角色说话，第一次会自动开一条私聊线 |
| `QuickChatGroupCreate` | 拉一个新群 |
| `QuickChatGroupManage` | 管理自己建的群：拉人 / 清退 / 限制回复 |

角色只能读写**自己参与**的会话 —— 别人的私聊它翻不到，这是刻意的隐私边界。

## 数据存放在哪

- 会话元数据与消息存在 Alife 的插件数据目录下（由 `QuickChatStore` 管理），**不在插件目录里**
- `Temp/Images`：粘贴 / 截图的图片缓存与缩略图，插件启动时清空
- `Temp/region-debug.log`：区域截图功能的调试日志，可随时删除

## 注意事项

- **目录名必须是 `Marisa.QuickChat`**（见文首）。
- 群聊里角色「没发言」通常不是 bug：没被 @ 到的时候它默认**不该**接话，这是刻意的。
  如果它确实想说却没说，多半是忘了调 `QuickChatSend` —— 「漏回复时自动提醒」会兜一手。
- 关掉「流式输出」会让长输出等得更久，除非你的模型/网络对流式支持不好，否则建议保持开启。
- 「显示所有消息」开启时，历史很长会让窗口一次性变高，可以配合「最大悬浮窗高度」限制。
