# 快聊 · Alife.QuickChat

面向 **Windows / Alife 5.1** 的快聊插件。插件 ID 为 `Marisa.QuickChat`，当前版本为 `5.1.0`。

通过全局快捷键（默认 `Alt+Q`）打开聊天窗口，复用 Alife 官方原生窗口与 WebView2。插件以 C# 源码由 Alife 加载，无需单独启动 Electron。

## 功能

- 私聊、多会话、自建小群；世界公共群聊与官方群聊双向同步。公共群聊接话由官方处理，自建小群继续使用快聊逻辑。
- 流式正文、Markdown、图片与文件；AI 思考和工具过程放在同一回复组合中，角色名显示在顶部，工具详情默认折叠。
- 简洁模式隐藏思考、工具过程和系统主动事件；完整模式将主动事件及没有发言的处理过程归并折叠。
- 默认主题、温暖晨曦、晴空映雪、星际幽蓝（动态）、极夜碳黑。默认主题保留原有自定义配色；星际主题包含随机星光和流星，支持减少动态效果。
- 局域网网页支持电脑和手机、私聊与群聊、角色颜色、创建和清空会话，以及文件选择、拖放和图片粘贴。
- 配置修改自动保存到当前角色或全局配置；支持窗口尺寸调整和聊天输入焦点恢复。

## 安装

1. 使用 Alife 5.1 Windows 客户端，安装依赖 `Alife.Function.FunctionCaller`。
2. 将发布 ZIP **内容**解压到 `Storage/Plugins/Marisa.QuickChat/`，使 `manifest.json` 直接位于该目录。
3. 重新加载插件或重启 Alife，在功能管理中启用快聊。世界群聊还需要客户端对应的官方世界群聊功能。
4. 升级前先退出客户端并备份原插件和配置，避免运行中文件占用。

## 局域网网页

在配置页启用“局域网访问”，使用页面显示的实际局域网地址，默认端口为 `17865`。手机须能访问电脑所在网络；连接电脑热点时使用热点网卡地址。服务监听可用网卡，接受本机和私有 IPv4 地址访问，按设计不设密码。仅在受信任的局域网开启；若无法连接，检查实际网卡地址及 Windows 防火墙入站规则。

附件每个不超过 20 MB，每条消息最多 8 个。网页上传暂存在本插件的 `Temp/Images/LanUploads/<会话>/`，停止局域网服务或正常退出时清理。源码和 DLL 附件使用惰性存储扩展名，避免被插件加载器误扫描；下载时保留原文件名。异常退出后可能留下临时文件，应退出客户端后清理。

## 开发与发布

主要源码位于仓库根目录，桌面和网页资源位于 `Resources/QuickChat/`。`ElectronQuickChatServices.cs` 是保留名称的兼容实现，当前窗口使用官方原生 API。

发布包根目录必须包含 `manifest.json`；不打包 `.git`、`Temp`、构建产物或个人配置。版本与依赖见 `manifest.json`，更新说明见 [CHANGELOG.md](CHANGELOG.md)。本仓库不包含 Alife 客户端及其依赖程序集。
